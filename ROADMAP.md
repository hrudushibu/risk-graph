# Roadmap — Risk Graph

Development plan for Risk Graph, an open-source security context graph platform.

## 🎯 Vision

Transform security from a list of isolated alerts into a unified graph showing how everything connects—making it trivial to answer "what's the actual risk?" and "how would an attacker move through our environment?"
